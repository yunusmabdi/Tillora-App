# Tillora

Tillora is a modern Android e-commerce application built with **Kotlin** and **Jetpack Compose**.

The app provides customers with a simple shopping experience, including product browsing, cart management, checkout, orders, account management, and customer authentication.

## 🚀 Features

- Customer registration
- Email verification with OTP
- Customer login
- Secure authentication with API tokens
- Browse products
- Product categories
- Product details
- Shopping cart
- Checkout
- Order history
- Order tracking
- Customer profile
- Edit profile
- Logout

## 🛠️ Tech Stack

### Android

- Kotlin
- Jetpack Compose
- Material 3
- Android Jetpack
- Navigation Compose
- ViewModel
- Kotlin Coroutines
- StateFlow

### Networking

- Retrofit
- Gson
- REST API

### Authentication

- Laravel API
- Laravel Sanctum
- Email OTP verification
- Token-based authentication

### Backend

The Android application communicates with a Laravel backend API.
